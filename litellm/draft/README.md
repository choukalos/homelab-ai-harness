# LiteLLM Draft Configs

Draft configuration files for LiteLLM MCP integration, tool bundles, and model aliases.

**Do not copy these into the live LiteLLM config.** They are templates for manual review.

## Files

| File | Purpose |
|---|---|
| `mcp-config.example.yaml` | MCP tool registration in LiteLLM |
| `tool-bundles.example.yaml` | Per-bundle tool groupings (family, coding, research, etc.) |
| `model-aliases.example.yaml` | Model alias definitions matching the alias registry |
