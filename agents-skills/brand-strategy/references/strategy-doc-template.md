# Strategy doc template (MKT-1)

The durable, versioned strategy doc of `brand-strategy` (MKT-1). One file per
site/brand at `docs/roles/marketing-strategist/strategy/<site>.md`. The
content half (sections 4–8) is S12's artifact — this template shows the full
MKT-1 doc: S12's sections wrapped with positioning, voice, and constraints.
Section order is the R9 Q2 synthesis: positioning → voice/brand image →
content constraints/guidance → pillars → measurement.

Field notes:

- **Section 2 is the load-bearing one for CM-1** — the QA pass checks voice
  against the table's do/don't examples. An attribute without examples per
  content type is an incomplete row (the "well-defined" rule, R9 Q1).
- **Calibration note is mandatory** — the "Calibrated against:" line names the
  materials the voice was extracted from (the G8 step). A voice defined with
  no calibration is a pet project (R9 Q1: the adjective exercise against the
  top performers).
- **Next review is a date, not a word** — the 3–6 month cadence (R9 Q4) needs
  a concrete date to be a cadence.
- **One site per doc** — Homelab Blog (traffic goal) and Bluebovine (lead-gen
  goal) are separate docs; shared voice attributes can be copied between them
  with the site-specific tone rules adjusted.
