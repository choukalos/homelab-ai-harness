# Pitch template

The 1-page shape of a `pm-exec-pitch` output. Source: R8
(`docs/research/R8-pm-artifacts.md`, PM-3 inputs — problem paragraph +
press-release summary + score with inputs + bottom-up range + competitive
one-pager).

```markdown
# <Opportunity> — pitch
- Date: <YYYY-MM-DD>
- Supports: <board idea id>
- Decision needed: <the one decision> — by <date or trigger>

## The opportunity (one line)
<one sentence the exec can repeat verbatim>

## Value at stake
<the bottom-up range + assumption list — or the equation + measurement
method when data is missing (never an invented figure)>

## Evidence
- <claim> — source: <link / report / data point>
- <claim> — source: <...>

## Options
1. **<Option A>** — what it is / cost / what it gives
2. **<Option B>** — what it is / cost / what it gives
3. **Do nothing** — what we keep, what we forgo

**Recommendation:** <option> — <one-line reason>

## The ask
<the decision needed + by when>
```

Rules: one page; answer-first (the opportunity + the ask are visible without
reading the evidence); every number sourced or stated as an equation; "do
nothing" present when it's a real alternative.
