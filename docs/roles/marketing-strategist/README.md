# Marketing Strategist artifacts

Durable strategist artifacts (G12 conventions — see `../README.md`):

- `strategy/<site>.md` — the durable, versioned strategy doc (MKT-1
  `brand-strategy` / S12 `content-marketing`): positioning, brand/voice
  definition, content constraints/guiding principles, pillars + topic clusters,
  funnel mapping, distribution, measurement, content calendar. One file per
  site/brand (e.g. `homelab-blog.md`, `bluebovine.md`); updates are edits with
  an "updated <date>" note.
- `impact-reviews/<site>-<YYYY-MM-DD>.md` — MKT-1 goal-vs-actual impact
  reviews (learnings + strategy deltas). Point-in-time; the strategy doc is
  the living artifact they feed.

Content asks are board cards on the content project (the ask template is the
card body) — the board is the artifact for in-flight asks.
