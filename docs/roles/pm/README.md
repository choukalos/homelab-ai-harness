# Product Manager artifacts

Durable PM artifacts (G12 conventions — see `../README.md`):

- `market-analysis-<area>-<YYYY-MM-DD>.md` — PM-1 `pm-market-analysis`
  opportunity briefs
- `prioritization-<YYYY-MM-DD>.md` — PM-5 `pm-prioritization` pass results
  (written rationale for the disposition of each idea)
- `prds/<feature>.md` — PM-2 `pm-product-requirements` PRDs (the durable copy;
  the board spec carries the PRD while the work is in flight)
- `pitches/<opportunity>-<YYYY-MM-DD>.md` — PM-3 `pm-exec-pitch` 1-page pitches

Ideation (PM-4) produces board ideas, not files — the board is the artifact.
