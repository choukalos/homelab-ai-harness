# Content Marketer artifacts

Durable CM artifacts (G12 conventions — see `../README.md`):

- `inventory.md` — the content inventory (CM-2 `content-inventory`): the
  registry of published content (URL, publish date, pillar, format, goal,
  performance when available). Single table, updated at publish time. The BA
  measures against it, the strategist reviews it (impact), the CM checks it
  before pitching (dedupe/repurpose).

Drafts live with the work (board card / project workspace) until they pass
content QA (CM-1 `content-qa`) and publish; the QA result rides on the card,
not here.
